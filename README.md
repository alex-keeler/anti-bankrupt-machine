# anti-bankrupt-machine
Custom web-based budgeting manager written in Rust, using the Rocket framework and a MySQL/MariaDB database

# First time setup
Build `Rocket.toml` and `.env` files from examples

# Run locally
Run `cargo run`

# Deploy
Run `./build-prod.sh` in repository directory

Move `target/aarch64-unknown-linux-gnu/release/anti-bankrupt-machine` file to `server:~/<backend install directory>/bin`
